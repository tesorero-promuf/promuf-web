Base de datos en Google Sheets — cómo importar

1. Crea la hoja en docs.google.com/spreadsheets con tu cuenta tesoreropromuf@gmail.com y nómbrala "Tesoreria PROMUF".
2. Crea 5 pestañas: PlanDeCuentas, Movimientos, Fondos, Socios y Conciliacion.
3. Importa los CSV de este repositorio: en cada pestaña usa Archivo → Importar → Subir y elige el archivo de la carpeta data/ (movimientos_template.csv, fondos.csv, conciliacion_template.csv, socios_template.csv) y plan_de_cuentas.csv en su pestaña.
4. Publica la hoja: Archivo → Compartir → Publicar en la web → selecciona cada pestaña → formato CSV → copia la URL de cada pestaña.
5. Pega las URLs aquí: botón ⚙ Config → guarda → el dashboard se conecta (solo lectura) y verás saldos, fondos y movimientos en vivo.
6. Flujo de trabajo diario: registras movimientos aquí → la API los escribe solos en la pestaña Movimientos de la hoja → la hoja queda como base de datos oficial y el dashboard la refleja al publicarse.

Reglas contables que cumple este sistema

• Depósito en 48 h de lo recaudado (Art. 15.i Estatutos).
• Rendición de eventos en máx. 15 días hábiles ante el Comité de Contraloría (Art. 10 R.CC).
• Orden de pagos: 1º honorarios músicos 100%, 2º gastos con factura, 3º excedente al Fondo de Autogestión (Art. 6-A).
• Fondo de Salud: ≥50% en moneda extranjera o USDT (Art. 6.d).
• Cuotas indexadas a USDT (Art. 6.c).
• Tabulador actualizado a tasa BCV cada 3 meses (Art. 11 R.CT).
• Auditoría trimestral de los 4 fondos + balance de comprobación trimestral (Art. 15.e Estatutos / Art. 5 R.CC).

Configuración — Google Sheets

Para publicar: Archivo → Compartir → Publicar en la web, elige la pestaña y formato CSV, copia la URL de cada pestaña. Las hojas publicadas permiten lectura sin clave (solo lectura).

Envío automático: con la URL de la API (ver scripts/agregar_movimiento.gs) en config.json, cada movimiento guardado se escribe solo en la pestaña Movimientos y queda blindado 🔒.
📌 Las URLs del config.json del repositorio tienen prioridad sobre estas al abrir la versión online; este formulario se usa cuando no hay config.json o para probar otra hoja. El campo de la API sí se puede sobrescribir localmente. Si pegaste enlaces pubhtml, se convierten a CSV automáticamente.
